# 材料排版工具（GB/T 9704—2012 / 市委办公室材料排版基本格式）

跨平台公文排版应用：将 `.docx` / `.doc` / `.wps` 文件拖入窗口或点击选择，一键完成全文排版。**默认采用 GB/T 9704—2012 党政机关公文格式**，市委办公室材料排版基本格式作为可选标签页。处理结果另存为「原名_排版.docx」，不改动原文件。

- **Windows**：`dist\材料排版工具.exe`（单文件免安装）
- **国产 Linux（deepin / 统信 UOS / 麒麟 Kylin，x86_64 / ARM64）**：`linux/install.sh` 一键安装，详见 [linux/README-Linux.md](linux/README-Linux.md)

## 两种格式标准

| 项目 | GB/T 9704—2012（默认） | 市委办公室材料排版基本格式 |
| --- | --- | --- |
| 页边距 | 上3.7 / 下3.5 / **左2.8 / 右2.6**（天头37mm、订口28mm，版心156×225mm） | 上3.9 / 下3.3 / 左2.7 / 右2.7 |
| A4、每面22行×每行28字撑满版心 | ✓ | ✓ |
| 标题二号小标宋居中、固定值33磅 | ✓ | ✓ |
| 正文三号仿宋_GB2312、固定值28磅、段首空2字 | ✓ | ✓ |
| 层次序数 | 一、黑体／（一）**楷体加粗**／1.（1）**仿宋加粗**（应用户实务习惯，GB 原文本不加粗） | 一、黑体／（一）**楷体加粗**／1.（1）**仿宋加粗** |
| 落款成文日期 | 三号**仿宋**、右空**四**字，署名以日期为准居中 | 三号**楷体**、右空**二**字，署名与日期右对齐 |
| 页码（四号宋体一字线、单右空一/双左空一、距版心约7mm） | ✓ | ✓ |
| 数字/西文 Times New Roman、全文黑色 | ✓ | ✓ |

界面顶部标签页切换格式（GB 为默认）；命令行用 `--preset gb9704|swb`（默认 gb9704）。

## 使用

**图形界面**：双击 `dist\材料排版工具.exe`（或运行 `py app.py`）

1. **直接把文档拖进窗口**（.docx / .doc / .wps），或点击「浏览…」选择文件
2. 按需调整选项（字体下拉框已自动匹配本机已安装字体）
3. 拖入后自动开始排版；手动选择时点击「开始排版」

**文件格式说明**：

| 输入 | 处理方式 |
| --- | --- |
| `.docx`（及内容为 docx 的 `.wps`） | 直接排版，无需安装任何 Office |
| `.doc` / 旧版二进制 `.wps`（OLE2） | 自动调用本机 WPS 或 Word（Windows）/ LibreOffice（Linux）转换为 .docx 后排版（独立进程，不影响已打开的窗口） |
| 输出 | **保持原文件格式**：「原名_排版.docx / .doc / .wps」（.doc/.wps 排版后经办公套件回写为相同二进制格式，回写失败自动降级为 .docx 并在日志说明） |

**命令行**（批处理/自动化场景）：

```bat
py app.py --cli 输入.wps                            :: 默认 GB/T 9704—2012
py app.py --cli 输入.docx --preset swb              :: 市委办公室材料排版基本格式
py app.py --cli 输入.docx --forwarding              :: 转发类通知（正文用楷体）
py app.py --cli 输入.docx --no-page-num             :: 不编排页码
py app.py --cli 输入.docx --keep-blank              :: 保留正文空行
py app.py --cli 输入.docx --title-font 宋体 --out D:\out.docx
```

## 排版规则 ↔ 实现对照

| 规范条款 | 工具处理 |
| --- | --- |
| 一、A4 幅面 210×297mm | 页面尺寸自动设置 |
| 二、页边距 上3.9 / 下3.3 / 左2.7 / 右2.7cm | 自动设置（多节文档逐节处理） |
| 三、每面22行、每行28字、撑满版心 | 文档网格行距与正文行距严格一致（560 缇=28 磅）并**关闭孤行控制**，每页恒定 22 行；字距 −849（28 字/行）；文字全部黑色 |
| 四、标题二号小标宋、居中、固定值33磅；日期三号楷体 | 自动识别首个非空段（及后续短行）为标题；标题下带括号或纯日期行按三号楷体居中 |
| 五、正文三号仿宋_GB2312、固定值28磅、段首空2字、回行顶格 | 全文正文段落自动套用；转发类通知勾选后正文改用三号楷体_GB2312 |
| 五、层次序数 一、/（一）/1./（1） | 依次自动套用 黑体 / 楷体_GB2312加粗 / 仿宋_GB2312加粗；**序数与正文同段时自动切分**（如"（二）工作目标。到2025年……"仅小标题部分用层次字体，接排正文仍为仿宋） |
| 五、段落之间不空行 | 默认删除正文多余空行（可关闭）；标题区空行保留 |
| —— | 标题（及其下日期行）之后自动空一行再接主送机关/正文（无空行则插入，多处空行只留一行） |
| 六、页码四号半角宋体、一字线、距版心下边缘约7mm；单页居右空一字、双页居左空一字 | 自动插入奇偶页脚「— N —」页码域，右/左缩进一字 |
| 七、数字用 Times New Roman | 所有中文 run 的西文字体统一设为 Times New Roman，数字自动呈现为 TNR |

其他自动化处理：**全部段落段前/段后间距强制归零**（并清除原文档残留的"行"单位段距与自动段距）；主送机关顶格（以"："结尾的首段）；**落款自动规范化**——原文"单位名称　　日期"写在同一行时自动拆分为两行（署名在上、成文日期在下），**落款与正文之间自动空三行**（多余删除、不足补插，联合署名之间保持紧凑），GB 格式日期三号仿宋右空四字、署名以日期为准居中，市委办格式日期三号楷体右空二字、与署名一同右对齐；**输出保持原文件格式**（.doc 进 .doc 出、.wps 进 .wps 出，回写失败时降级为 .docx 并提示）；段首多余全角空格清理；层次序数独立成段（整行）与接排正文（句号切分）两种写法均正确分体设字体；自动编号/底纹/彩色/倾斜/加粗等无关修饰清除（图片段落自动改单倍行距防止被固定行距裁切）；表格内文字统一中文字体、黑色与数字 TNR（字号保持原样）。

## 明确不做的事（需人工把握）

- 多行标题的**宝塔形/菱形分行**：涉及词意切分，请先在原文按词意断行，工具会逐行按标题格式编排；
- 红头、红色分隔线、版记、空白页不排页码等印制细节；
- 「段尾单字不成行」：Word 的避头尾规则已开启（`wordWrap=0` 使数字/年份不折行），单字不成行如出现需手动微调缩进。

## 字体说明

推荐目标机器安装：**方正小标宋简体**（标题）、**仿宋_GB2312**、**楷体_GB2312**、黑体、宋体。
未安装时 Word/WPS 会自动用近似字体替换，也可在界面下拉框中改选本机已有字体（如 华文中宋、仿宋、楷体）。

## 开发与测试

```bat
py make_sample.py        :: 生成格式混乱的测试样例
py test_gongwen.py       :: 43 项 XML 断言（版面/网格/页码/字体/层次序数/接排切分）
build.bat                :: PyInstaller 打包单文件 exe（含拖拽组件）
```

核心引擎在 `gongwen.py`（`format_file()` 可独立调用）；界面与命令行入口在 `app.py`；版式参数（页脚距离、网格等）集中定义在 `gongwen.py` 文件头部，可按需微调。
