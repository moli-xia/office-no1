# 材料排版工具 · 国产 Linux 安装使用说明

适用系统：**deepin（深度）**、**统信 UOS**、**麒麟 Kylin V10/SP1** 等 Debian/apt 系国产桌面系统（x86_64 / ARM64 飞腾·鲲鹏均可）。

## 安装（一次性，需联网）

**本目录（linux/）已自包含全部所需文件，整体拷贝到目标电脑（U 盘/内网传输均可），在终端执行：**

```bash
cd linux
./install.sh
```

目录内已含程序源码（`app.py`、`gongwen.py`），无需再从别处拷贝任何文件。

脚本可**重复运行**（幂等）：每次自动清理并重建运行环境；安装中断后再跑一次即可。

脚本自动完成：

1. 检查并按需安装系统组件（`python3-tk`、`python3-venv`，此处需要输入一次 sudo 密码）；
2. 在 `~/.local/opt/clpb` 创建独立运行环境（venv，不污染系统 Python），从国内镜像安装 `python-docx`、`tkinterdnd2`；
3. 用 PyInstaller 在**本机**构建独立可执行程序（不打扰系统其他组件）；
4. 在应用启动器注册「材料排版工具」图标（办公分类）。

安装完成后即可**离线使用**，在启动器搜索「材料排版工具」点击启动；也支持把 `.docx / .doc / .wps` 文件直接拖入窗口。

- 打包失败时自动降级为"脚本直跑"模式（启动器图标功能完全相同）；
- Python 3.7 系统（UOS V20 / 麒麟V10）自动先把 venv 内 pip/setuptools/wheel 升级到可用末版（pip 24.0），解决旧 pip 无法解析新包元数据的问题；核心依赖 python-docx 若仍装不上，自动改走 apt（`python3-docx`）兜底；
- 拖拽组件（tkinterdnd2）为可选依赖，安装失败自动降级为「浏览…」按钮选文件，不影响排版功能；
- 系统缺 `python3-venv` 时自动补装并重试；仍不可用则降级为「系统 pip --user」模式；
- 以 root 运行时免 sudo；无 sudo 权限的用户在系统已带 `python3-tk`/`pip` 时也不需要提权；
- 彻底卸载：`uninstall.sh`。

## 命令行使用

```bash
~/.local/opt/clpb/bin/材料排版工具 --cli 材料.docx
~/.local/opt/clpb/bin/材料排版工具 --cli 材料.wps --forwarding
```

## 各系统注意事项

| 事项 | 说明 |
| --- | --- |
| 旧格式 `.doc` / 二进制 `.wps` | 自动调用 **LibreOffice**（`soffice`）转换为 .docx 后排版。WPS Linux 版**不支持后台转换**，故安装脚本会自动检查/补装 libreoffice-writer；若网络原因未装成，工具会弹窗引导「用 WPS 打开 → 另存为 .docx → 重新拖入」（一键调起 WPS） |
| ARM64（飞腾/鲲鹏）/ 龙芯 | 应用与排版功能完整可用；个别架构若无拖拽组件二进制，拖入功能自动降级为「浏览…」按钮选择文件，其余不受影响 |
| 字体 | 生成的 docx 中写入的是规范字体名（方正小标宋简体/仿宋_GB2312 等）。国产系统政府版多预装方正字库；若本机未装，WPS/Word 打开时自动替换显示，正式印发建议在装有公文字体的机器上查看 |
| 输出 | 一律为「原名_排版.docx」，不改动原文件 |

## 为什么要在目标机器上构建？

Linux 应用与系统 glibc、CPU 架构强相关，跨机交叉打包兼容性差（国产系统覆盖 x86_64、ARM64、LoongArch 多架构）。本方案在目标机器原生构建一次，即得到该架构下真正"独立、免依赖"的可执行程序——这是国产系统部署的通行做法。若多台机器架构相同，也可在一台构建后把 `~/.local/opt/clpb/bin/材料排版工具` 单文件拷贝到同架构机器直接运行，再用 `install.sh --no-build` 补图标。
